# スーパーマリオ アドベンチャー

`index.html` をブラウザで開くだけで遊べる、横スクロール 2D プラットフォームゲームです。
NEW スーパーマリオブラザーズ風の手ざわりを目指して、物理・レベル・演出をすべて作り直しました。

## 遊びかた

`index.html` をダブルクリックしてブラウザで開くだけ。インターネット接続もサーバーも不要です。

### 操作

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | ← → / A D | 画面左下の ◀ ▶ |
| ジャンプ | スペース / Z / ↑ | 右下の ▲ |
| ダッシュ | Shift / X | DASH ボタン |
| ファイアボール | Shift / X（ファイア中） | DASH ボタン |
| すり抜け床を降りる | ↓ | － |
| ポーズ | P / Esc | － |
| 音の ON/OFF | M | 右上のボタン |

## 収録内容

- **全 5 ステージ**（草原 / 夜 / 空 / 地底 / クッパ城）＋ 各ステージに中間ポイント
- **マリオの 3 段階**：チビ → スーパー（キノコ）→ ファイア（フラワー）／スターで一定時間無敵
- **敵**：クリボー、ノコノコ（甲羅を蹴れる）、トゲゾー、パックンフラワー、ジュゲム、ハンマーブロス、クッパ
- **仕掛け**：？ブロック、壊せるレンガ、土管、すり抜け床、左右／上下に動く床、落ちる床、トゲ、溶岩、水
- **ゴール**：旗ポール（高い位置でつかむほど高得点）→ お城へ
- **スコア**：連続踏みつけコンボ、コイン 100 枚で 1UP、クリア時のタイム換算ボーナス
- 効果音と BGM はすべて Web Audio でその場で合成（音声ファイル不要）
- グラフィックもすべてコード内のドット絵から生成（画像ファイル不要）

## 前バージョンからの主な修正

| 症状 | 原因 | 対応 |
| --- | --- | --- |
| コインやアイテムが空中から落ちてくる | 物理ボディに重力がかかったまま配置 | タイル／固定エンティティとして配置し直し |
| 穴の位置が毎回変わり、跳べない穴ができる | `Math.random()` で地面を生成していた | 全ステージを手作業のレベルデータに（穴は最大 5 タイル＝必ず跳べる） |
| ？ブロックを叩いても何も起きない | 当たり判定と中身の処理が未実装 | 下から叩く判定・中身の抽選・使用済みブロック化を実装 |
| ミス時に残機が一気に減る／多重に再開する | 死亡処理に多重呼び出し防止がなかった | 状態機械で 1 回だけ実行するように |
| やり直すたびにコンソールに警告が出る | アニメーションを毎回重複登録していた | アセットを一度だけ生成する方式に |
| 敵が床の端から落ちて消える | 端の判定がなかった | 足元をチェックして折り返すように |
| 敵・コインが数千個あって重い | 大量に配置していた | 画面に近づいた敵だけ動かす方式＋配置量を調整 |
| 外部 CDN が落ちるとゲームが起動しない | Phaser を CDN から読み込んでいた | 依存ライブラリを廃止し、1 ファイルで完結 |

## 開発メモ

- 内部解像度 512×288（16px タイル × 32×18）を 2 倍で描画し、CSS で画面サイズにフィットさせています。
- 物理は自前のタイル AABB 判定。すり抜け防止のためサブステップ移動をしています。
- ジャンプはボタンを離した瞬間に重力が強くなる可変ジャンプ、コヨーテタイム、先行入力に対応。
- `mario-*.png` は現在使っていません（同じドット絵を JS 内に取り込んでいます）。削除しても動きます。
- `index-old-phaser.html.bak` は書き換え前の Phaser 版のバックアップです。
